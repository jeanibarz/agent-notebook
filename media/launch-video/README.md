# Launch film

The source of the 49-second film embedded at the top of the repository README. The film is a web
page: one paused animation timeline whose picture is a pure function of time. The same page is
stepped frame by frame in headless Chromium to make the video, and can be opened in a browser to
play live.

Every command, id, score and output line the film shows inside the notebook, the `cat` and the
`git diff` is real output of `nb` 0.10.0, captured in `demo-film.txt` (a temporary notebook with
`NB_MAX_LINES=4`, so an eviction fits on screen). The failing and passing test lines in the opening
and closing scenes are an illustration, not product output or a measurement.

This folder is not part of the npm package and nothing in `src/` depends on it.

## Files

| File | What it is |
|---|---|
| `storyboard.md` | The build contract: narration times, rules for every scene, each scene's events and text. |
| `script.json`, `captions.js` | The narration, and its caption track (generated by `audio/align-voice.py`). |
| `film.html`, `film.css`, `engine.js`, `player.js` | The page, the timeline engine, live playback. |
| `components.js`, `scenes-a.js/.css`, `scenes-b.js/.css` | The shared notebook element and the ten scenes. |
| `vertical.html/.css/.js` | The 9:16 cut: the same stage, cropped per scene, with large captions. |
| `thumb.html` | The two thumbnail options, rendered through the same engine. |
| `render.mjs` | Frame grabber: steps `film.seek(t)` in headless Chromium and writes PNGs. |
| `build.sh` | Narration, aligned narration, mix, frames, videos, contact sheets. |
| `audio/` | Local narration (Kokoro), music and effects synthesizer, mixer, cue sheet. |
| `demo-film.txt` | The real terminal capture the film's on-screen text comes from. |

## Rebuilding it

Nothing here runs in CI. To rebuild you need Node.js, ffmpeg, a headless Chromium with
`playwright-core`, and a Python with `numpy`, `scipy`, `soundfile` and `kokoro_onnx`.

Two things are not committed and must be added under `vendor/`:

- `vendor/gsap.min.js`: GSAP 3.12.5 (one file, from its CDN build).
- `vendor/fonts.css` and `vendor/fonts/`: Fraunces, Inter and JetBrains Mono as local `@font-face`
  rules, so a frame never depends on the network.

```sh
export KOKORO_DIR=/path/to/kokoro-model-folder
export PLAYWRIGHT_CORE=/path/to/node_modules/playwright-core   # if not resolvable from here
PY=python3 SHARDS=8 ./build.sh all        # writes out/release/*.mp4 and out/contact-sheet-*.png

AT=4.1,18.4,46.5 node render.mjs film.html out/stills   # a few stills at exact times
```

The picture was timed against a reference voice. The final narrator is a blend of two voices
whose sentences `audio/align-voice.py` places on the reference voice's cues, so the picture's hits
land on sentence starts whichever voice speaks.
