# Security Policy

## Supported Versions

`agent-notebook` is published to npm from a single maintained release line.
Security fixes land on the latest `0.5.x` release; please upgrade to the newest
published version before reporting, in case the issue is already fixed.

| Version | Supported          |
| ------- | ------------------ |
| 0.5.x   | :white_check_mark: |
| < 0.5   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues,
discussions, or pull requests.** Disclosing a vulnerability in the open puts
other users at risk before a fix is available.

Instead, report it privately through GitHub's security advisory flow:

- Open the repository's
  [**Security** tab → **Report a vulnerability**](https://github.com/jeanibarz/agent-notebook/security/advisories/new),
  which starts a private advisory visible only to you and the maintainer.

Please include enough detail to reproduce the issue — affected version, a
description of the problem, and steps or a proof of concept if you have one.

## What to Expect

This is a small, single-maintainer open-source project, so responses are
best-effort rather than bound by a formal SLA:

- We aim to acknowledge a report within about a week.
- If the report is accepted, we will work with you on a fix and coordinate a
  release; if it is declined, we will explain why.
- Please give us a reasonable chance to release a fix before any public
  disclosure.

Thank you for helping keep `agent-notebook` and its users safe.
